# EVON

EVON is an experimental programming language project written in Go.

The project explores a different approach to programming, centered around structure, constraints, and state transitions rather than conventional procedural patterns.

## Concept

EVON is built around three fundamental ideas:

- **Entities** — data and structure.
- **Laws** — rules and constraints.
- **Flows** — state changes and movement.

The goal is to explore how these concepts can work together to express logic with less repetitive code and fewer unnecessary conditional checks.

## Status

EVON is currently under active development. Its architecture, syntax, and core functionality are still evolving.
